# Shared dispatch

Read once per invoked assignment, alongside the selected mode. Provider references below are conditional.

Pure orchestration delegates substantive work. Supporting delegation permits requested direct execution. Retain choices through compaction. Variant selects pool preference, not host. Never change the parent model.

## Selection and authority

Honor explicit profiles and active bindings. Slots are jobs, not stages or worker counts. Shared models do not merge jobs. Rebinding preserves roles, lifecycle, and review authority. Task fits are preferences, not measured effort-specific specialties.

Choose the earliest suitable eligible slot, not a cheap-first sequence. General slots permit all roles. One-off slots require fresh bounded workers, never continuing controllers. Specialist slots take precedence for their role, without banning others' tools. Role-restricted reviewers do not preempt general candidates solely on task fit.

Role/lifecycle exceptions require user authorization and an exact profile. Out-of-pool choices also require a pool exception. Inspector flags `--role-override` and `--allow-out-of-pool` record exceptions, not authority. Never import another mode's fences or substitute unavailable routes except the conditional Fable fallback.

Use native workers for the host provider with exact model/effort and verified tools/session access. External Codex under Claude uses the optional [controller adapter](../../../docs/controller-designs.md), subject to mode-specific designs.

Give workers objectives, inputs, disjoint write ownership, acceptance checks, profiles, and deadlines. Sequence dependent/overlapping writes. The controller integrates and accepts. Authors cannot be the sole acceptance check. Reviewers need reassignment to fix. Analysis/tools do not authorize implementation or external mutations.

Preserve host permissions and selected tools, approvals, timeouts, and account routes. Routing imposes no permission policy. Broader checks require profile selection, not silently widened access. Never change accounts, global settings, or capacity automatically.

## Capacity and completion

No default router ceiling applies. Honor runtime/provider/project and assignment-wide caps across descendants. Positive `max_parallel_workers` counts workers. Positive `max_external_sessions_per_assignment` counts all active external-provider runs together, including Muse and durable T3. Native workers consume worker capacity only. Idle threads consume no active capacity. Null/omitted caps add no ceiling.

Claude helpers may delegate within permissions/tools/pool/roles/scope/ownership/context isolation. Pass variant, mode, bias, fences, remaining budgets, limits, and allocations to descendants. Subdivide allocations, never clone them. Request unallocated capacity only for capped resources. An external-session cap does not gate uncapped native workers. Null/omitted caps require no allocation. Native Codex workers remain leaves unless assigned team roles. External workers cannot recursively launch opposite controllers. Helpers add no votes, diversity, or coordinators.

Preserve lifecycle, cancellation ownership, completion handling, and shared deadlines across continuations. Prefer completion events. Verify exact session ownership and delivery before promising continuation.

- Diagnose product, evaluator, infrastructure, provider, or authority failures before escalating. Retry only with changed inputs, supported transient conditions, or new diagnostic hypotheses.
- Transfer evidence only while its assumptions hold. Run affected and required checks. Preserve candidate identity, mode-required fresh independent reviews, and same-version ratification.
- Keep controls proportional to actual risks and requirements. Finish after acceptance and verification. Continue independent ready work around blockers.

Required independent reviews use fresh native workers or provider sessions, never forked/resumed author/reviewer conversations. Check inherited memory/project context. Use session-scoped isolation. Disclose unresolved contamination instead of claiming independence. Exclude prior verdicts from fresh independent-review packets. Selected modes may share debate, ratification, or informed critique under their own context protocols. Those later exchanges are not fresh independent reviews. Targeted verification is not independent acceptance or a vote.
